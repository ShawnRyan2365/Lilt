# Lilt

轻快接力，继续手头的工作。

原生 SwiftUI macOS 26+ 菜单栏工具，管理本机 Claude Pro / Max 凭据与额度。工具栏、面板和浮层用 Apple 原生 Liquid Glass（`glassEffect`），内容区是灰色画布上的白色物件，系统字体和 SF Symbols。模型请求由官方 Claude Code 直接发出。

## 当前交付

2026-10-09：**0.1 研究预览版**。可构建与运行；不是已经通过全部 PRD 验收的正式版。

- 菜单栏面板、概览、账号排序/备注/停用/删除、设置、快捷键与脱敏诊断。
- 浏览器登录入口：在临时独立配置和钥匙串作用域执行官方 `claude auth login --claudeai`，结果保存到 Lilt 钥匙串；支持取消、180 秒超时与授权码输入。
- 手动长效 OAuth Token：安全输入、钥匙串存储；能力与完整 OAuth 分别展示。
- 实验性 OAuth usage 查询，5 小时 / 7 天独立显示；过期、缺失、错误和限流有独立处理。
- 专属作用域的凭据同步适配器，带事务日志、受限权限、外部修改检测与条件回滚。**应用成功只代表写入，不代表 CLI 已采用新身份。**
- 内存演示模式：三个明确标注的虚构账号，阈值接力和无候选暂停；退出还原真实资料，不保存演示数据。

**真实自动接力已开放，尚未用真实账号验证。** 打开开关后，当前账号任一窗口剩余额度达到阈值时，Lilt 按顺序读取其他账号的额度，把第一个确认可用的账号写入作用域；没有可用账号时暂停并逐个说明原因。为了让它能连续工作，凭据的处理方式与 ORCA 相同：

- **续期**：不在用的完整登录，访问令牌快到期时由 Lilt 向官方令牌端点续期（与官方 CLI 相同的请求）。正在作用域里的账号从不由 Lilt 续期，留给官方 CLI，避免两边用掉同一个刷新令牌。
- **读回**：官方 CLI 给当前账号续期后，Lilt 把新凭据收回保存。能证明是同一个登录时自动完成（刷新令牌没变，或账号身份一致，必要时向官方 profile 接口核对）；证明不了时暂停，由人选择“采纳”或“改回”。
- **身份**：切换时把账号身份写进作用域的 CLI 配置，让 `/status` 跟着换。身份记录和凭据一样只存钥匙串。此前添加的账号会在下一次成功读取额度时补记。

长效 Token（`claude setup-token`）只能发模型请求，官方额度接口不接受它，所以这类账号看不到额度，也不参与自动接力；可以手动切换到它。运行中的 CLI 是否立即用上新账号仍未实测，切换后请在 CLI 里用 `/status` 核对。当前不会终止、恢复或重放用户 CLI 操作。

## 构建与打开

需要 macOS 26+ 与 Swift 6.2+。无第三方依赖；本机 Command Line Tools 即可构建，不要求完整 Xcode。装有 Xcode 时，打包脚本会顺带编译强调色资源，让系统绘制的控件也用 Lilt 绿；没有时退回系统强调色。

```sh
swift run LiltChecks
./scripts/build-app.sh
open build/Lilt.app
```

也可以用 Xcode 打开 `Package.swift`。产物为本地 ad-hoc 签名，未公证、未发布。当前打包脚本生成本机架构版本。

第一次启动时，概览页一次只显示一步：添加账号、启用 Lilt 专属作用域、选一个账号、用启动命令打开 Claude Code。点击“先看看演示”体验界面和规则，不需要真实账号。开启演示自动接力后点击“模拟到阈值”，可观察切号和重复事件处理。真实模式中，确认启用专属作用域后才能切换账号。

概览只回答三件事：现在用的是哪个账号、两个窗口各剩多少、下一个接力的是谁。每个账号是一个带眼睛的小角色，额度偏低时眯眼，到阈值或停用时闭眼；点“接力顺序”里的角色即可切换；需要处理的状态只出现一条，指上去展开说明。界面的设计令牌、组件和动效集中在 `Sources/Lilt/Design/`。

默认快捷键 ⌘⌥L 打开或收起菜单栏面板，设置中可改为 ⌘⌥J / ⌘⌥K。系统拒绝注册时提示；其他应用占用同一组合无法检测。同一份应用只运行一个实例。

## 数据与边界

- 普通资料：`~/Library/Application Support/Lilt/accounts.json`，仅本地 UUID、备注、能力状态和额度，不含实际凭据。
- 长期凭据与账号身份记录：macOS 钥匙串 `app.lilt.accounts`。
- CLI 专属范围：`~/Library/Application Support/Lilt/scope`；兼容运行时凭据文件为 0600，目录为 0700。
- 不读取 ORCA 账号库，不修改 `~/.claude`，不修改 shell 配置、网络或代理。
- `transaction.json` 仅存摘要与事务状态。外部修改或未完成事务会阻止继续覆盖；当前没有自动崩溃恢复。
- 网络请求只有三种，都发往官方域名并拒绝重定向：读额度（`api.anthropic.com/api/oauth/usage`）、核对账号身份（`api.anthropic.com/api/oauth/profile`）、给不在用的登录续期（`platform.claude.com/v1/oauth/token`）。无模型推理接口调用。
- 原生无障碍语义、可见状态文字、跟随系统减少透明度与减少动态效果；动效只在状态变化时出现，无持续动画。完整 VoiceOver 实机验收仍待完成。
